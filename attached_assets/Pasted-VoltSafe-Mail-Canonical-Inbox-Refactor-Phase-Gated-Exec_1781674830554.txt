VoltSafe Mail — Canonical Inbox Refactor (Phase-Gated Execution Spec)

Mission

We have spent multiple days fixing symptoms:

* Inbox counts don’t match visible messages
* Unread count says 223 but only 13 load
* “No messages found” while unread count > 0
* Smart Inbox counts disagree with badges
* Priority / Unread collisions
* Missing INBOX drift
* Repeated backfills

The diagnosis is that inbox truth is currently computed in multiple places using multiple definitions.

This refactor is intended to create:

* One inbox definition
* One canonical query layer
* One source of truth for counts and rows
* Server-side filtering before pagination
* Thin frontend renderer

IMPORTANT:

This is NOT permission to rewrite VoltSafe Mail.

Do not touch:

* Gmail sync correctness
* Reply / Reply-all
* Forwarding
* Tracking
* Signatures
* CTA injection
* CID rendering
* CRM linking
* Thread rendering
* Account impersonation
* Permissions
* Existing email-body functionality

The goal is to replace inbox truth computation, not rebuild the mail system.

⸻

CRITICAL VOLTSAFE PRODUCT DECISION

Claude’s draft defaulted to Gmail-only Inbox membership.

That is NOT the VoltSafe Mail product decision.

VoltSafe Mail is a CRM / command center, not a Gmail clone.

We intentionally want category mail visible in VoltSafe Inbox.

Therefore:

Canonical VoltSafe Inbox Membership

A message belongs to VoltSafe Inbox if:

* INBOX
    OR
* CATEGORY_PERSONAL
    OR
* CATEGORY_UPDATES
    OR
* CATEGORY_PROMOTIONS
    OR
* CATEGORY_SOCIAL
    OR
* CATEGORY_FORUMS

AND NOT:

* SPAM
* TRASH
* DRAFT
* SENT

This policy must exist in exactly one place.

Do NOT rewrite Gmail labels.

Do NOT backfill INBOX labels.

Do NOT mutate Gmail truth.

Gmail label_ids remain authoritative.

VoltSafe Inbox membership is a read-time product decision.

Set:

INBOX_INCLUDES_CATEGORY_SKIP = true

The canonical predicate becomes:

VoltSafe Inbox =
(INBOX OR CATEGORY_*)
AND NOT spam/trash/draft/sent

All counts, rows, categories, Smart Inbox groups, unread filtering, and pagination must derive from that one predicate.
