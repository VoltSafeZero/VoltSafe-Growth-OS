1. Pre-deploy audit

Before deploying, verify:

- npm run build passes
- all CEO Cockpit test suites pass
- startup migrations are idempotent
- no undefined pool usage remains
- no silent migration catch blocks remain
- no CREATE INDEX without IF NOT EXISTS in CEO migration blocks
- no destructive SQL
- no production data copy required
- no auto-send paths
- no external API calls in deterministic CEO services
- no private Currents exposure
- no DM body broad exposure
- no sensitive localStorage storage
- no fake runway/cash numbers

Report findings before changing anything.

3. Production migration checklist

Verify production deploy logs show:

- CEO Action Queue tables ready
- meeting_notes.one_on_one_sections column ready
- ceo_execution_reviews table ready
- board_packs table ready
- ceo_forecast_notes table ready

If a migration fails:
- do not copy dev database to production
- do not drop production tables
- do not delete production data
- inspect the failing SQL
- make migration idempotent
- rerun deploy only after the fix

6. Production monitoring

For the first 24 hours after deploy, watch for:

Server logs:
- migration errors
- 401/403 spikes
- 500 errors on CEO routes
- slow CEO route responses
- failed DB queries
- missing column/table errors

Browser:
- blank Today page
- tab switching issues
- copy button errors
- board-pack access errors
- mobile overflow

Database:
- ceo_action_queue rows created only by explicit actions
- ceo_action_events rows logged correctly
- ceo_execution_reviews created only by review/dismiss actions
- board_packs created only by explicit generation/create actions
- ceo_forecast_notes created only by explicit scenario note actions

7. Rollback readiness

Document rollback triggers:

Rollback if:
- Today page fails for normal users
- login/session breaks
- production migration corrupts or blocks startup
- CEO Cockpit APIs cause widespread 500s
- permissions expose CEO/CFO-only data
- Board Pack exposes capital data incorrectly

Do not rollback for:
- missing empty state polish
- one non-critical tab error if Today still loads
- copy button issue that has no data exposure
- expected 403s for unauthorized users
