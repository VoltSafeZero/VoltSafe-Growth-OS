This is not just a display problem. VoltSafe Mail’s search is almost certainly searching a narrower dataset than Spark.

The strongest clue is this:

* Spark reports 307 emails found
* VoltSafe Mail returns only a small subset
* Several “missing” Spark results are threads where Scott is a participant or appears in an older message, but Scott may not be the sender of the newest message in the thread

What is probably happening

VoltSafe Mail is likely doing one or more of these:

1. Searching only the latest message in each thread
    If Scott sent an earlier message, but the latest reply came from James, Sanad, Tiffany, or someone else, the thread may not match.
2. Searching only the visible Inbox folder
    “Inbox → All” appears to mean all inbox categories, not Gmail’s full All Mail history. Spark may include archived, sent, categorized, and older messages.
3. Searching only cached/synced messages
    VoltSafe may query its local database rather than Gmail directly. If only a limited sync window was imported, older messages simply do not exist in VoltSafe’s search index.
4. Matching sender fields too narrowly
    VoltSafe may search only the normalized from_email of the displayed message, while Spark searches:
    * From
    * To
    * CC
    * BCC
    * Thread participants
    * Every message inside the thread
    * Body text and quoted headers
5. Pagination or result caps
    The backend may fetch only the first 50 or 100 records and then apply the search filter afterward. That creates silent missing results—a classic “looks fine until you compare it to reality” bug.
6. Thread collapsing
    Spark may count individual messages, while VoltSafe displays one row per thread. That explains some count difference, but it does not fully explain the visible missing conversations.

The most likely core bug

VoltSafe Mail appears to be searching the summary record for a conversation, rather than searching every underlying Gmail message and participant within that conversation.

That would explain why a thread such as:

* “Scott, Sanad, Miguel, Kent”
* “Scott, Miguel”
* “Zach, Paula, Walden”
* “Scott Carlson”

can appear in Spark but disappear in VoltSafe—even though Scott is clearly involved.

This needs to be treated as a data-integrity issue

A mail search cannot quietly omit emails. That destroys trust in the entire system. Fancy AI summaries are useless if the email itself has vanished into the digital couch cushions.
