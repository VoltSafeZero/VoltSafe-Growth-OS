client/src/data/training-hub.ts

- storyboardPath

1. In client/src/pages/training-hub.tsx, add a new admin/demo-only section called:

   Publishing Checklist

2. This section should only be visible to:
   - admin users
   - master_admin users
   - demo mode users

3. Add summary counts:
   - Total videos
   - Hosted
   - Edited
   - Raw recorded
   - Not recorded
   - Needs update

4. Add a compact progress bar:

   - Label example:
     “0 of 6 videos hosted”

5. Add a “Next Actions” panel.

   Priority logic:
   - If any video has status needs_update:
     Show: “First priority: update stale videos.”

     Show: “Next priority: edit raw recordings into final MP4s.”

     Show: “Next priority: upload edited MP4s and paste hosted URLs.”

     Show: “Next priority: run the missing recording scripts.”
   - Else if all videos are hosted:
     Show: “All onboarding videos are hosted and ready.”

   Columns:
   - Video
   - Status
   - Raw recording
   - Final MP4
   - Hosted URL
   - Storyboard
   - Next action

7. Per-video table rules:

   Raw recording:
   - ✅ if rawVideoPath exists and status is one of:
     raw_recorded, edited, hosted, needs_update
   - Otherwise show —

   Final MP4:
   - ✅ if finalVideoPath exists and status is one of:
     edited, hosted, needs_update
   - Otherwise show —

   Hosted URL:
   - ✅ if videoUrl exists and status is hosted
   - Otherwise show —

   Storyboard:
   - ✅ if storyboardPath exists
   - Otherwise show —

8. Next action rules:
   - not_recorded → Run recording script
   - raw_recorded → Edit into MP4
   - edited → Upload and paste hosted URL

   - needs_update → Re-record or update video
