Add a “Recent News” intelligence feature to VoltSafe CMS for Leads, Accounts, Contacts, Partners, and any other CRM entity profiles where strategic context matters.

Purpose:
Users need a place to paste/add relevant news article URLs connected to a Lead, Account, Contact, Partner, Marina, Utility, Port, Investor, or other CRM entity.

The system should ingest the article URL, extract/summarize the relevant context, and make that information available to VoltSafe AI when generating emails, suggested next actions, outreach timing, account strategy, meeting prep, and lead prioritization.

This feature should answer:

- What recent news is happening around this lead/account/contact/partner?
- Is there a timely reason to reach out?
- Does this news create a strategic opening for VoltSafe?
- How should this change our outreach angle?
- Should this news influence the next email, call, meeting, or follow-up?

Feature Name:
Recent News

Where to add it:
Add a “Recent News” section/card inside the profile/detail views for:

- Leads
- Accounts
- Contacts
- Partners
- Marinas, if applicable
- Utilities, if applicable
- Ports, if applicable
- Investors, if applicable
- Any shared CRM entity detail page that supports AI context

If these entity types share a common profile component, build it once as a reusable RecentNewsPanel component.

Core User Workflow:

1. User opens a Lead/Account/Contact/Partner profile.
2. User finds the “Recent News” section.
3. User clicks “Add News”.
4. User pastes a news article URL.
5. User can optionally add a short note explaining why the article matters.
6. System saves the URL.
7. System fetches metadata and article text where possible.
8. System creates an AI summary and strategic relevance summary.
9. The summarized/compressed context becomes available to the AI when generating emails, next actions, lead strategy, account summaries, meeting prep, and suggested outreach.

API Requirements:

Create backend endpoints:

GET /api/crm/recent-news?entityType=lead&entityId=123
Returns recent news items for that entity.

POST /api/crm/recent-news
Creates a news item.

Body:
- entityType
- entityId
- url
- userNote
- relevanceType
- tags

PUT /api/crm/recent-news/:id
Updates user note, tags, relevance type, archive status, etc.

DELETE /api/crm/recent-news/:id
Soft delete or archive preferred.

POST /api/crm/recent-news/:id/refresh-summary
Re-fetches article metadata/text and regenerates AI summary.

POST /api/crm/recent-news/:id/generate-outreach-angle
Generates a short suggested outreach angle using this news item and the CRM entity context.

POST /api/crm/recent-news/:id/use-in-email-context
Marks this news item as important for the next AI-generated email.

Article Ingestion Requirements:

When a user adds a URL:

1. Normalize the URL.
2. Check if the same URL already exists for the same entity.
3. Fetch article metadata:
   - title
   - source/publication
   - author, if available
   - published date, if available
   - description/meta excerpt, if available
4. Extract readable article text where possible.
5. If full article text cannot be extracted, use available metadata, page title, OpenGraph description, and user note.
6. Generate AI summary.
7. Generate strategic relevance.
8. Generate suggested outreach angle.
9. Generate key points.
10. Assign AI relevance score from 1 to 5.

AI Summary Requirements:

For each article, generate:

1. Brief Summary
Plain-language summary of what happened.

2. Why It Matters to VoltSafe
Explain why this article may be relevant to VoltSafe’s marine shore power, smart pedestal, smart connector, safety, leakage detection, energy management, marina modernization, utility, port, or electrification strategy.

3. Strategic Relevance
Explain whether this creates a reason to:
- reach out now
- wait
- monitor
- escalate
- prepare a proposal
- reconnect with a dormant lead
- mention in a follow-up email
- use as meeting prep

4. Suggested Outreach Angle
A concise outreach angle that could be used in an email or call.

Example:
“Congrats on the recent marina infrastructure announcement — it looks like safety, modernization, and electrification are becoming priorities. VoltSafe may be relevant because we help marinas modernize shore power with safer smart pedestals, smart connectors, and software visibility.”

5. Key Points
3 to 5 bullet points.

6. Relevance Score
1 to 5:
- 1 = General background only
- 2 = Mildly relevant
- 3 = Useful context
- 4 = Strong outreach trigger
- 5 = High-priority strategic trigger

2. Suggested next actions

- follow-up timing

3. Lead/account/contact summaries

4. Meeting prep

5. Strategic account view
If the account has high-relevance news, surface it as an insight.

Context Compression Rules:

Do not dump full article text into every AI prompt.

Instead, compress news into a short structured format:

Recent News Context:
- Title
- Source
- Published date
- AI summary
- Why it matters
- Suggested outreach angle
- Relevance score
- User note

When multiple articles exist:
- Prioritize highest relevance score
- Then newest published date
- Then newest added date
- Include max 3 full news summaries
- Compress older/lower relevance articles into 1-line bullets

Add this to AI prompt context only when relevant.

Error Handling:

If URL fetch fails:
- Save the URL anyway
- Show status: “Could not fetch article automatically”
- Allow user to manually enter title/source/summary/note
- AI can still summarize using user note and metadata if available

If article is behind paywall:
- Save metadata and URL
- Show message: “Full article text may not be available. Add a note if there is specific context we should remember.”
- Do not fail the entire workflow.

If duplicate URL:
- Warn user:
“This article is already attached to this record.”
- Allow user to add a new note if needed.

Security Requirements:

- Validate URL format
- Only allow http/https URLs
- Prevent script injection in title, notes, summary, and extracted text
- Do not render raw HTML from articles
- Use plain text only
- Enforce server-side permissions
- Rate limit article fetch/summary generation endpoints
- Avoid SSRF risks:
  - Block localhost/private IP ranges
  - Block internal network addresses
  - Follow redirects safely
  - Enforce timeout
  - Limit max response size
