Please perform a safe product/UI rename for the VoltSafe CMS internal communications feature.

Rename the user-facing product name from:

Current

to:

Currents

Important scope

This should be a UI/product language change only unless a technical rename is truly necessary.

Do not rename database tables, backend API routes, query keys, or core technical identifiers unless absolutely required.

Keep these technical names as-is for safety:

* /current
* /api/current/*
* current_messages
* current_channels
* current_read_receipts
* current_mentions
* current_pins
* current_reactions
* existing component/file names if renaming them creates unnecessary risk

The goal is that users see Currents in the app, while the internal plumbing can remain current.

Rename requirements

Update visible UI text from Current to Currents wherever it refers to the product/module name.

Examples to update:

* Main sidebar nav item:
    * Current → Currents
* Main page title/header:
    * Current → Currents
* Empty states:
    * “No Current messages” → “No Currents messages” or better: “No messages in this Current yet”
    * Use natural wording, not awkward forced pluralization.
* CRM record sections/tabs:
    * Current → Currents
    * Example:
        * Account → Currents
        * Contact → Currents
        * Opportunity → Currents
        * Lead → Currents
* Section labels:
    * “Account Current”
    * “Lead Current”
    * “Current — team discussion”
        should become:
    * “Account Currents”
    * “Lead Currents”
    * “Currents — team discussion”
* Search UI:
    * “Search Current”
    * “Search this Current”
        should become:
    * “Search Currents”
    * “Search this Current” is acceptable if it refers to one specific stream, but prefer “Search this conversation” if that reads better.
* Notifications / copy:
    * “Mentioned in Current”
    * “Current mention”
        should display to the user as:
    * “Mentioned in Currents”
    * or more specifically “Mentioned in #general”

Important wording guidance

Use Currents for the product/module.

Use Current only if referring to one individual stream/conversation and the sentence naturally needs singular wording.

Examples:

Good:

* Currents
* Search Currents
* Open in Currents
* Currents — team discussion
* No messages in this Current yet

Avoid awkward wording:

* No Currents messages
* Currentss
* Currents Current
* Current Currents
