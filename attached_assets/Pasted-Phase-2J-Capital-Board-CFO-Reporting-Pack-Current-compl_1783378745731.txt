4. Reporting API

Add APIs behind requireCapitalAccess:

GET /api/capital/reports
- returns available report types and recent generated/saved reports if storage exists

GET /api/capital/reports/:type
Query params:
- round_id optional
- date_from optional
- date_to optional
- format optional: json, markdown, csv if supported
- include_sensitive optional

Returns structured report JSON by default.

POST /api/capital/reports/:type/generate
- generates a report snapshot
- optionally stores generated report metadata if existing pattern supports it

If persistent report storage does not exist, implement stateless generation first.
