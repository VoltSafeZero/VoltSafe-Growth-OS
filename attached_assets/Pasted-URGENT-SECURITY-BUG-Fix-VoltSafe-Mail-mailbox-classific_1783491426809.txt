Correct business rules:

A) Domain classification
- Any mailbox ending in @voltsafe.com is a VoltSafe business mailbox.
- Any mailbox NOT ending in @voltsafe.com is a private/personal/external mailbox.
- Examples:
  - trevor@voltsafe.com = Business / VoltSafe mailbox
  - alex@voltsafe.com = Business / VoltSafe mailbox
  - sales@voltsafe.com = Business / VoltSafe mailbox
  - support@voltsafe.com = Business / VoltSafe mailbox
  - trevor@hyalos.com = Private mailbox
  - burgesstrevor76@gmail.com = Private mailbox
  - any @gmail.com = Private mailbox
  - any non-@voltsafe.com = Private mailbox

B) Team inbox classification
A mailbox is a Team Inbox ONLY if:
- it ends in @voltsafe.com
AND
- it is explicitly configured as a shared/team inbox in the database/settings
AND
- the current user has permission to access that shared/team inbox

A mailbox must NOT be treated as a Team Inbox simply because:
- it exists in the CMS
- it belongs to another user
- it is visible to admin somewhere
- it has Gmail connected
- it has messages
- it is “business visible”
- it is attached to a user account

C) User business inbox classification
A mailbox like trevor@voltsafe.com is:
- a VoltSafe business mailbox
- owned by that user
- not automatically a Team Inbox
- only visible to its owner and admins with explicit mailbox-admin permission
- should not appear under Team Inboxes unless explicitly shared as a team inbox

D) Private inbox classification
A mailbox like trevor@hyalos.com or burgesstrevor76@gmail.com is:
- Private
- not Business Visible
- not Team Inbox
- not visible to other standard users
- not shown under Team Inboxes
- accessible only by the connected owner, unless explicit admin-level mailbox access rules say otherwise
