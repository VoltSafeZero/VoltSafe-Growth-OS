Build a “Snippets & Templates” feature inside the VoltSafe Mail client.

Goal:
Allow users to create, edit, delete, search, categorize, and insert reusable canned email snippets into newly composed emails or replies.

UI:
Use the existing modal layout shown in the screenshot:
- Modal title: “Snippets & Templates”
- Subtitle: “Reusable replies that can be inserted into any email with one click.”
- Left panel:
  - Search bar
  - Category filter
  - “+ New” button
  - List of snippets with title, preview text, category, and edit icon
- Right panel:
  - If no snippet selected: empty state message
  - If snippet selected: editable form
    - Snippet title
    - Category dropdown
    - Subject line field
    - Body textarea
    - Variables help text
    - Buttons: Save, Insert, Duplicate, Delete
- Add close X in top right.

Functionality:
- Store snippets locally first using localStorage.
- Support manual creation of unlimited new snippets.
- Support editing and deleting snippets.
- Support duplicating snippets.
- Support inserting snippet body into the active email compose/reply window.
- Support inserting subject line into subject field when composing a new email.
- Support merge variables:
  {{firstName}}
  {{lastName}}
  {{marinaName}}
  {{companyName}}
  {{senderName}}
  {{calendarLink}}
- Before insert, replace known merge variables from the selected contact if available.
- Leave unknown variables as-is so the user can manually edit them.

Technical requirements:
- Use React with TypeScript if the app already uses it.
- Make the component reusable: SnippetsModal.
- Props should include:
  isOpen
  onClose
  onInsertSnippet
  activeContact
  isNewEmail
- Use localStorage key: voltsafe_mail_snippets_v1
- If no localStorage exists, load the default snippets above.
- Keep styling consistent with current VoltSafe Mail UI.
- Use clean cards, light borders, teal accent color, rounded corners.
- Make it mobile responsive.
- Add a small “Variables” helper section beside the editor.
- Add toast notifications for saved, deleted, duplicated, and inserted snippets.
- Make sure manually created snippets persist after refresh.

Important:
Do not remove the existing compose or reply functionality.
This should enhance the mail client, not replace it.
