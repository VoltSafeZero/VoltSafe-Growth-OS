Implementation Phase 1 — Recommendation correctness

Verify and fix if needed:

Current meeting:

* Must be a timed event.
* Must not be all-day.
* Must not be _team.
* Must not be cancelled.
* Must not be a Focus block.
* If multiple active events overlap, prefer:
    1. external/CRM event
    2. event with meetingUrl
    3. earliest start time

Next meeting prep:

* Only within 60 minutes.
* Must be external or CRM-matched.
* Must not be internal-only.
* Must not be all-day.
* Must not be focus block.
* If meeting already started, it belongs in current meeting, not next.

Recently finished:

* Ended within last 2 hours.
* Must be external or CRM-matched.
* Must not already have outcome.
* Must not be all-day.
* Must not be _team.
* Prefer most recently ended.

Task:

* Prefer overdue before due today.
* Prefer high priority if task priority exists.
* Prefer meeting follow-up tasks if tied.
* Must not recommend already completed tasks.
* Must not recommend already scheduled tasks if scheduled state exists or session scheduled set exists.

Open focus window:

* Minimum 30 minutes.
* Prefer the next upcoming open window, not one that has already started unless currently open and still has >=30 minutes left.
* Do not recommend open window if an urgent task exists.
