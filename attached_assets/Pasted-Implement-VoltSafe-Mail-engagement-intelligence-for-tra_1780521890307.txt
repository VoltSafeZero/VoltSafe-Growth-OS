Implement VoltSafe Mail engagement intelligence for tracked signature CTA clicks.

Objective:
When a recipient clicks a tracked signature CTA such as “Watch a Demo,” surface that as a high-intent sales signal across VoltSafe Mail and CRM.

Do not rebuild tracking. Use the existing signature CTA click tracking already implemented.

---

# Core Feature

Create an engagement intelligence layer that detects high-intent contacts based on:

- signature CTA clicks
- repeated clicks
- recent clicks
- email opens, if existing tracking supports it
- no reply after engagement

Example signal:

High Intent Contact
John Smith clicked “Watch a Demo” 3 times
Last click: 14 minutes ago
Suggested action: Follow up

---

# Scoring Rules

Add simple first-pass rules:

1. Demo CTA clicked once
Signal:
Interested

2. Demo CTA clicked 2+ times
Signal:
High Intent

3. Demo CTA clicked 3+ times within 7 days
Signal:
Very High Intent

4. Demo CTA clicked but no reply within 24 hours
Signal:
Follow Up Recommended

5. Demo CTA clicked by multiple people from same account
Signal:
Account Heating Up

---

# Where To Show Signals

Add engagement signals to:

1. Contact record
- latest CTA clicked
- total CTA clicks
- last click time
- intent level

2. Account record
- total CTA clicks across contacts
- number of engaged contacts
- most-clicked CTA
- account intent level

3. Mail thread view
Show a small banner:

“John clicked Watch a Demo 3 times — follow-up recommended.”

4. CRM Review / Lead view if applicable
Surface contacts/accounts with recent high-intent activity.

---

# Suggested Actions

For high-intent contacts, show suggested actions:

- Follow up now
- Send demo booking link
- Create task
- Add note
- Move lead/account stage forward

Do not auto-create tasks yet unless the system already supports user-controlled task creation. Show suggestions first.

---

# Backend

Create or extend an engagement summary service.

Suggested computed fields:

contact_engagement_summary:
- contact_id
- account_id
- last_signature_cta_clicked
- last_signature_cta_clicked_at
- total_signature_cta_clicks
- unique_signature_ctas_clicked
- demo_click_count
- intent_level
- suggested_action
- updated_at

If a physical table is overkill, start with a query/service that computes this from existing tracking tables.

Prefer computed service first unless performance requires materialization.

---

# Intent Levels

Use:

- none
- interested
- high_intent
- very_high_intent

Rules:

none:
0 CTA clicks

interested:
1 demo CTA click

high_intent:
2+ demo CTA clicks or any CTA clicked in last 24 hours

very_high_intent:
3+ demo CTA clicks in 7 days or 2+ contacts from same account clicked demo CTA
