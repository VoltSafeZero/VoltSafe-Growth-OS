========================
PHASE 3 — DOMAIN MATCHING ENGINE
========================

Create utility: normalizeDomain(input)
- lowercase
- trim
- remove '@'
- strip protocol if present
- return clean domain

Create utility: extractSenderDomain(fromField)
- parse email string
- extract actual email
- split at '@'
- return domain

Create service: routeEmailToFolders(email)

Steps:
1. Get email.owner_user_id
2. Extract sender domain
3. Load ALL folder domain rules for that owner_user_id
4. Match using:
   - exact match OR
   - ends_with (domain OR .domain)

Example:
nmma.org matches:
- nmma.org
- events.nmma.org

But NOT:
- nmma.org.fake.com
- fake-nmma.org

5. Insert into email_folder_assignments:
- owner_user_id = email.owner_user_id
- assigned_by = 'system'
- assignment_reason = 'domain match: {domain}'

Must be idempotent (no duplicates)
