Please perform a VoltSafe CMS Currents Phase 7C Notes audit and polish pass only.

Do not add Guest Currents, direct messages, slash commands, external collaborators, workflow automation, AI classification, new task features, or unrelated CRM features.

Goal

Verify that optional notes for Decision / Risk / Requirement marks work cleanly across Currents.

Phase 7C added:

* note dialog when marking Decision / Risk / Requirement
* optional 500-character note field
* pre-filled existing note when editing
* Update / Mark / Unmark flow
* note dot indicator on inline badge
* note tooltip on badge
* notes displayed in Structured panels

This audit should verify the feature is stable, polished, and regression-free.

Audit only:

Backend/API checks

Verify:

1. POST /api/current/messages/:id/structured accepts notes.
2. Notes are trimmed before storage or safely handled.
3. Empty notes are stored consistently:
    * preferably null or empty string, but be consistent.
4. Notes update on existing item via upsert.
5. Notes do not create duplicate structured items.
6. Notes are returned in:
    * message GET payloads
    * thread GET payloads
    * record GET payloads
    * GET /api/current/structured
7. Max-length handling is safe.
8. Very long notes do not break backend or UI.
9. Deleted messages cannot receive new notes/marks.
10. Auth is still required.
11. No SQL errors.
