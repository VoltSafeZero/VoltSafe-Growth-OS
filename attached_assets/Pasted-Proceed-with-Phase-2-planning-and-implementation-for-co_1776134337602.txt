Objective:

Core requirements:

2. Conversion must create or link the Organization using the existing accounts/accounts-based Organizations model
3. Conversion must write a traceability record into migrationMap
4. Conversion must avoid duplicates by checking for likely existing Organizations before creating a new one
5. Conversion must preserve backward compatibility and existing lead data
6. No bulk conversion tools in this phase

Expected conversion behavior:
- user selects a lead
- system offers “Convert to Organization”
- system checks for possible existing Organization matches based on:
  - name similarity
  - email/domain
  - phone
  - website if available
- if a likely match exists, user can:
  - link lead to existing Organization
  - or create a new Organization anyway
- if no suitable match exists, system creates a new Organization
- converted_from_lead_id must be populated where applicable
- migrationMap must record the relationship and conversion event
- lead should remain historically preserved, not deleted
