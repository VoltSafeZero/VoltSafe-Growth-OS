Avatar security verification

Verify:

1. POST /api/me/avatar requires auth.
2. DELETE /api/me/avatar requires auth.
3. GET /api/user-avatars/:fileName requires auth.
4. User can mutate only their own avatar.
5. Upload accepts JPEG.
6. Upload accepts PNG.
7. Upload accepts WebP.
8. Upload rejects SVG.
9. Upload rejects GIF unless explicitly intended.
10. Upload rejects non-image MIME types.
11. Upload rejects files over 2 MB.
12. Upload does not trust original filename.
13. Stored filename is UUID/safe.
14. Path traversal is impossible.
15. File-serving route cannot read arbitrary files.
16. Old avatar cleanup cannot delete arbitrary files.
17. Delete/reset clears avatar safely.
18. /api/auth/me returns safe avatarUrl.
19. Avatar URL does not expose filesystem paths.

Fix only security or reliability issues directly related to avatar upload.
