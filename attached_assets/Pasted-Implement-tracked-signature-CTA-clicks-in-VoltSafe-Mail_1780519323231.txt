Implement tracked signature CTA clicks in VoltSafe Mail, with the default CTA pointing to a clean VoltSafe demo landing page.

Objective:
Extend VoltSafe Mail’s existing email tracking system so signature CTA clicks — especially the “Watch a Demo” image — are wrapped in tracked redirect URLs, logged, tied to CRM/email engagement, then redirected to:

https://voltsafemarine.com/demo

Do not send users directly to YouTube unless this page is unavailable.

# Important Architecture Rule

Do not permanently store per-recipient tracking URLs in signature templates.

Store the clean destination URL in the signature/CTA config.

Generate tracking URLs only at send time because each token must be recipient/message specific.

# Send-Time Wrapping

Find the existing email send pipeline where:
- email HTML body is assembled
- signature HTML is appended
- current open/click tracking is applied

Add signature CTA wrapping there.

Rules:
- Wrap only links inside the signature block.
- Do not accidentally rewrite normal email body links unless existing tracking already does.
- Do not double-wrap existing VoltSafe tracking URLs.
- Preserve image alt text, width, and styling.
- Generate one tracking token per sent email + recipient + CTA/link.
- For multiple recipients, create per-recipient tokens where current sending architecture allows it. If not, document limitation clearly.

# Public Redirect Endpoint

Create:

GET /track/signature-click/:token

Behavior:
1. Validate token.
2. Log click event.
3. Capture timestamp, user agent, and privacy-safe IP metadata if existing tracking does.
4. Update CRM/email engagement activity.
5. Redirect 302 to the clean destination URL.

Security:
- Only allow http/https destination URLs.
- Block javascript:, vbscript:, data:text/html, file:, and other unsafe protocols.
- Return 404 or safe fallback for invalid token.
- Tokens must be random, unguessable, and non-sequential.
- Do not expose internal IDs in public URLs.
