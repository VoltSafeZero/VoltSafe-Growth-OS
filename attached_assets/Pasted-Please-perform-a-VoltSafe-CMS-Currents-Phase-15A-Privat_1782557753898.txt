Verify that Private Channels / Channel Membership is secure, complete, regression-free, and production-safe.

Schema / migration checks

Verify:

1. current_channel_members exists.
2. Unique (channel_id, user_id) exists.
3. FK to current_channels(id) uses ON DELETE CASCADE.
4. FK to users(id) uses ON DELETE CASCADE.
5. created_at exists.
6. created_by exists if implemented.
7. current_channels.is_private exists.
8. is_private defaults to false.
9. Migration is idempotent.
10. Existing public channels remain public.
11. No existing channel visibility changed unexpectedly.

* canViewChannel
