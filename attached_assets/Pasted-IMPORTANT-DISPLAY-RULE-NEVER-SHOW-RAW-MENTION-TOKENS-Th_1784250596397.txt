IMPORTANT DISPLAY RULE — NEVER SHOW RAW MENTION TOKENS

The structured token:

@[Scott Carlson](user:138)

may be used internally for storage or transport, but it must never be visible anywhere in the VoltSafe CMS user interface.

Users must always see only the canonical human-readable full name.

Example:

User types:
@Scott

After selecting Scott Carlson, everyone must see:
@Scott Carlson

They must never see:
@[Scott Carlson](user:138)

- While composing
- After selection
- Saved task descriptions
- Task comments
- CURRENTS messages
- Lead notes
- Account notes
- Contact notes

- Notifications
- Today
- Daily Execution

COMPOSER BEHAVIOUR

When the user selects Scott Carlson from autocomplete:

1. Replace the typed query:
   @Scott

2. Display:
   @Scott Carlson

3. Store Scott Carlson’s immutable user ID separately in structured mention metadata.

4. Keep the internal ID hidden from the editor’s visible text.

Preferred model:

Visible text:
@Scott Carlson

Structured metadata:
{
  "type": "mention",
  "userId": "138",
  "label": "Scott Carlson",
  "start": 24,
  "end": 39
}

Do not require the visible textarea value to contain:

@[Scott Carlson](user:138)

If the current implementation stores tokens inside the raw text field, the editor must transform them into a clean display layer before rendering and must transform them back only internally when saving.

However, the preferred architecture is to store:

- Clean visible text
- Separate structured mention metadata

Example database fields:

content_text:
“@Scott Carlson please review this.”

content_mentions_json:
[
  {
    "userId": "138",
    "label": "Scott Carlson",
    "start": 0,
    "end": 15
  }
]

This avoids leaking implementation syntax into the UI.

- @Scott
- @scott
- @sco
- Scott’s username
- Scott’s email

But after selection, the visible result must always become:

@Scott Carlson

The same rule applies to all users:

@Terri → @Terri Breker

Always display:

First Name + Last Name

Do not display:

- Username
- Email prefix
- First name only
- Initials
- Raw database IDs
- Mention syntax
- Internal token markup
