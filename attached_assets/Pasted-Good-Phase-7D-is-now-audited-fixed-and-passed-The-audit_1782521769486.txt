Goal

Allow users to export structured Currents items as a CSV from the Structured Items Panel.

Structured item types:

* Decisions
* Risks
* Requirements

The export should work for:

1. /current Structured Panel
2. Record Currents Structured Panel

Use the currently loaded and currently filtered items client-side if possible. Do not add backend export routes unless absolutely necessary.

Scope

Add only:

1. CSV export button in /current Structured Panel
2. CSV export button in Record Structured Panel
3. Export currently visible/filtered items
4. Include key fields in the CSV
5. Safe CSV escaping
6. Helpful empty-state behavior

Export behavior

When a user clicks export:

* Download a .csv file
* Use currently displayed items, respecting:
    * selected scope
    * selected filter
    * current channel vs All Currents
    * selected record in Record Structured Panel

Examples:

* Current channel + All filter exports all loaded structured items for current channel.
* Current channel + Decisions filter exports only decisions for current channel.
* All Currents + Risks filter exports all loaded risk items.
* Account record + Requirements filter exports requirements for that account.

CSV columns

Include these columns:

1. Type
2. Message Preview
3. Notes
4. Message Author
5. Marked By
6. Created At
7. Source
8. Message ID
9. Thread Root ID
10. Action URL

Optional if easily available:

11. Record Type
12. Record ID
13. Channel

CSV escaping requirements

Implement safe CSV escaping:

* Wrap fields in quotes when needed
* Escape quotes by doubling them
* Preserve commas/newlines safely
* Prevent spreadsheet formula injection for cells beginning with:
    * =
    * +
    * -
    * @

For formula-like values, prefix with a single quote '.

File naming

Use a useful filename.

Examples:

* voltsafe-currents-structured-general-all-2026-06-26.csv
* voltsafe-currents-structured-general-decisions-2026-06-26.csv
* voltsafe-currents-structured-all-risks-2026-06-26.csv
* voltsafe-currents-structured-account-123-requirements-2026-06-26.csv

Use local date or ISO date.

UI requirements

/current Structured Panel

Add an export button near the panel header or filters:

* Export CSV
* or small download icon + CSV

Behavior:

* Disabled if there are no currently displayed items.
* Tooltip or title explains what will export:
    * “Export visible structured items”
* Button should not crowd the filter chips.
* Dark mode should look good.

Record Structured Panel

Add same export button in compact form.

Behavior:

* Disabled if no displayed record items.
* Exports only visible/filtered record items.

Backend

Use existing loaded displayed items in the frontend.

Only change backend if a necessary field is missing.
