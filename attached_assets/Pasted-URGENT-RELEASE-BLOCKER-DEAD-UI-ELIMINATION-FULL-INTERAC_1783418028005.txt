URGENT RELEASE BLOCKER — DEAD UI ELIMINATION & FULL INTERACTION AUDIT

OBJECTIVE

Perform a comprehensive audit of every page, module, modal, drawer, toolbar, card, button, icon button, chip, badge, segmented control, dropdown, menu item, tab, floating action button, quick action, context menu, table action, and interactive component that has been created or modified within the last 48 hours.

This is a release-blocking task.

There must be ZERO enabled controls anywhere in the application that do nothing when clicked.

═══════════════════════════════════════
PRIMARY REQUIREMENT
═══════════════════════════════════════

Every interactive element must do exactly one of the following:

• Navigate somewhere
• Open a page
• Open a modal
• Open a drawer
• Open a side panel
• Save data
• Update data
• Delete data
• Duplicate data
• Create a record
• Export data
• Import data
• Trigger an AI workflow
• Open a picker
• Open a menu
• Filter data
• Sort data
• Search
• Display meaningful information
• Execute its intended workflow

OR

If the functionality is intentionally unavailable, the control must:

• Be visually disabled
• Use disabled styling
• Have cursor-not-allowed
• Have appropriate aria-disabled attributes
• Display a tooltip explaining why it is unavailable

Under no circumstances should an enabled button, chip, icon, tab, or menu item do absolutely nothing.
