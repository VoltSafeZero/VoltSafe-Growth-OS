VoltSafe CMS — CEO Cockpit Phase 9: Forecasting, Scenario Planning, and Runway Intelligence

Goal:
Build a deterministic CEO forecasting and scenario planning layer that turns live CMS data into forward-looking operating scenarios.

This should help answer:
- Are we on track?
- What is likely to slip?
- What risks affect runway, revenue, product, and funding?
- What happens in Base / Upside / Downside scenarios?
- What CEO actions improve the outcome?

Context:
Earlier phases built:
- Phase 4: CEO Cockpit insights
- Phase 5: 1:1 notes and commitments
- Phase 6: CEO Action Queue
- Phase 7: Daily/Weekly CEO Briefing and Leadership Agenda
- Phase 8: Execution Intelligence / Drift Detection

Phase 9 should sit between Execution Intelligence and Board Pack reporting.

Important:
This is not financial advice.
This is not scientific prediction.
This is deterministic planning intelligence from local CMS data.

No external API calls.
No auto-send.
No AI dependency.
CEO/CFO-sensitive financial/runway sections must be permission-gated.

Do not present this as certainty.

5. Runway intelligence

GET /api/today/ceo-forecast/runway

This section must be CEO/CFO/capital-gated.

If no reliable cash/burn data exists, return:
- clear empty state
- no fake runway number
- list of missing inputs needed:
  - current cash balance
  - monthly burn
  - expected receivables
  - committed funding
  - planned hires/spend
  - expected grant/funding inflows

If data exists, return:
- current cash if available
- monthly burn if available
- estimated runway months
- committed funding
- expected funding
- revenue inflows
- downside runway
- upside runway
- key risks
- recommended CEO actions

Never invent financial numbers.
Never estimate cash/burn unless source data exists.
Label all assumptions clearly.

6. Revenue forecast

GET /api/today/ceo-forecast/revenue

Use existing CRM opportunities.

Return:
- total open pipeline
- weighted pipeline if probability data exists
- forecast by expected close month
- high-confidence opportunities
- stale opportunities
- slipped opportunities
- at-risk opportunities
- expected next 30/60/90 day movement
- blockers to revenue
- recommended CEO actions

If probability/amount/close date data is missing, return honest empty states per field.

7. Execution forecast

GET /api/today/ceo-forecast/execution

Use Phase 8 Execution Intelligence.

Return:
- forecasted slips
- commitments likely to miss
- recurring risks likely to continue
- owner load risks
- blockers likely to age
- stale tasks likely to remain stale
- execution wins likely if current actions complete
- recommended interventions

Rules:
- all routes require auth
- forecast route requires admin
- runway/funding routes require CEO/CFO/capital access
- no route may send email
- no route may send Currents messages
- intervention actions must use Phase 6 CEO Action Queue
- scenario-note should save a local note only if a suitable notes table exists; otherwise return copy-only text
