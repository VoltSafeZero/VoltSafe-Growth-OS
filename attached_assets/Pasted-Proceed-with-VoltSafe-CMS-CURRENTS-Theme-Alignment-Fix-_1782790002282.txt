Goal

The current CURRENTS/Slack-lite custom background treatment does not work visually, especially in light mode. It makes CURRENTS feel disconnected from the rest of VoltSafe CMS.

Change CURRENTS so it matches the existing VoltSafe CMS global light and dark themes.

CURRENTS should still be polished and premium, but it should no longer use a separate futuristic waterflow/dark backdrop that overrides the app theme.

Current problem

In dark mode:

* CURRENTS is readable but too separate from the CMS theme.
* The custom dark/water backdrop makes it feel like a different product.
* It creates unnecessary visual noise behind messages.

In light mode:

* The main CMS shell is light.
* CURRENTS content remains dark.
* This creates a jarring mixed-theme experience.
* Text and contrast are weaker.
* It feels unfinished instead of premium.

CURRENTS must use the same design language as the rest of VoltSafe CMS:

CURRENTS should use the normal dark theme surfaces:

* app dark background

* subtle teal accents only where consistent with the app

Light mode

CURRENTS should use the normal light theme surfaces:

* light page background
* light sidebar/channel panel background
* light message area
* readable dark text
