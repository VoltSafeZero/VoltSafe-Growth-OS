Make CURRENTS message feeds and file/attachment displays feel more like the familiar Slack experience the VoltSafe team is used to, while keeping VoltSafe’s premium Growth OS identity.

6. light/dark consistency

1. Rich image preview polish

Slack makes images feel native in the feed. Improve CURRENTS image attachments.

For image attachments:

* show larger inline previews where appropriate
* preserve aspect ratio
* cap max width/height so giant images do not dominate
* use rounded corners
* use subtle border/shadow
* keep filename visible but not noisy
* show download/open affordance on hover if existing route supports it
* maintain reactions below/near the attachment cleanly
* support light and dark mode

Do not break attachment-only messages.

2. File card polish

For non-image attachments:

Create/upgrade a compact file card style:

* file icon/type
* filename
* file size if available
* download/open action
* subtle border/background
* hover state
* clear contrast in light/dark mode

Examples:

* PDF
* DOC/DOCX
* XLS/XLSX
* CSV
* generic file

Do not add document previewing unless already available.

3. Files tab polish

Phase 19A added a Files tab using existing message attachments.

Upgrade it to feel intentional:

* show attachment cards grouped/listed cleanly
* include sender name
* include date/time
* include channel/DM context where useful
* image thumbnails for image files
* compact file cards for documents
* good empty state:
    * “No files shared yet”
    * “Files attached in this conversation will appear here.”
* maintain channel/DM privacy/access behavior

Do not build global cross-channel file search in this phase.

4. Attachment hover actions

Where low-risk, add hover actions:

* Open
* Download
* Copy link only if safe/existing
* no action if route not available

Do not expose private file URLs to unauthorized users.

Do not add public sharing.

5. Reaction placement polish

Make reactions look clean under messages with attachments.

Verify:

* reactions under image attachments are not too far away
* reactions under file cards are aligned
* reaction add button remains visible on hover
* attachment-only messages still allow reactions
* deleted messages do not show attachment actions incorrectly

6. Feed density and hierarchy

Adjust only if needed:

* message spacing
* avatar alignment
* filename spacing
* timestamp readability
* date divider spacing
* hover action positioning

Do not make messages cramped.

7. Light and dark mode

Verify image/file cards in:

* light mode
* dark mode

Light mode should not look washed out. Dark mode should not look too neon.

Use existing tokens where possible.
