PART 1 — Processing UX (critical)

Problem:
Right now user clicks Stop → nothing obvious happens.

Fix:

1. Add processing state UI in meeting-notes-detail:
   - If status === "processing":
     show:
       - spinner
       - text: "Analyzing meeting..."
       - disable actions

2. Add polling:
   - When status === "processing":
     poll GET /api/meeting-notes/:id every 2–3 seconds
     stop when status === "completed" or "failed"

3. On completion:
   - auto-refresh tabs
   - scroll to Summary tab
   - subtle highlight animation
