Proceed with VoltSafe CMS Currents Phase 9C only: Archived Channel Visibility / Structured Panel Polish.

Do not work on Accounts, Contacts, CRM list views, group DMs, Guest Currents, external collaborators, slash commands, workflow automation, notification preferences, typing indicators, or unrelated task features.

Goal

Polish how archived channel content appears across read-only Currents surfaces.

Phase 9A added channel archive/unarchive. Phase 9B made archived channels truly read-only. Phase 9C should make archived channel content clear, discoverable, and not confusing in panels like Structured Items, Search, Mentions, Pins, Summaries, and View in Currents links.

Scope

Work only on read-only visibility and labeling for archived channels.

Focus on:

1. Structured Panel archived-channel visibility/filtering
2. Search result labeling for archived channels
3. Mentions panel labeling if archived-channel mentions appear
4. Pins panel behavior for archived channels
5. View in Currents links to archived messages
6. AI summary behavior/read-only labeling if needed
7. Archived channel badges/labels in read-only surfaces
8. Tests/audit for the above

Do not add new write features.

Before coding, inspect:

* GET /api/current/structured

Desired behavior

Archived channel content should remain readable, but clearly labeled.

Structured Items

Archived channel structured items should either:

1. Be shown by default with an Archived badge, or
2. Be hidden by default with a clear Include archived channels toggle.

Preferred for Phase 9C:

* Show active-channel items by default.
* Add a checkbox/toggle: Include archived channels.
* When included, archived-channel items show an Archived badge beside the channel/source label.

Do not delete or mutate archived structured items.

Search

Search results from archived channels should remain accessible.

Requirements:

1. Archived-channel search results should show an Archived badge.
2. Clicking result should open archived channel/message safely.
3. Read-only banner should appear after navigation.
4. No write controls should appear.

Mentions

If a user was mentioned in an archived channel:

1. Mention should remain visible.
2. It should show an Archived badge or archived channel label.
3. Clicking mention should open read-only archived channel/message safely.

Pins

Existing pins in archived channels should remain visible/readable.

Requirements:

1. Pins route should include archived channel pins when viewing archived channel.
2. Pin UI should show read-only state.
3. Unpin controls should be hidden/disabled for archived channels.
4. Archived badge appears where helpful.

View in Currents / Task Source Links

For links pointing to archived channel messages:

1. Link should still work.
2. Archived channel should open safely.
3. Read-only banner should appear.
4. Message/thread highlight should still work if implemented.
5. No write controls should appear.

Backend requirements

Add archived metadata to read-only responses where needed.

Possible fields:

{
  "channelArchivedAt": "2026-06-26T..."
}

or:

{
  "isChannelArchived": true
}

Audit each route and add archived metadata only where useful:

* structured items
* search results
* mentions
* pins
* task source/current links if needed

Avoid payload bloat.
