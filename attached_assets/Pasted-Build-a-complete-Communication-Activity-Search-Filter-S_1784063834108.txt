Build a complete Communication Activity Search, Filter, Sort, and Follow-Up system across VoltSafe Growth OS Pipeline records.

PRIMARY GOAL

Upgrade Pipeline > Leads & Accounts and Pipeline > Contacts so users can immediately identify:

- Who VoltSafe has not contacted recently
- Who is waiting for a VoltSafe response
- Who VoltSafe is waiting to hear back from
- Which leads have gone stale
- Which leads have never been contacted
- What the most recent communication was
- Whether the latest communication was incoming or outgoing
- Which communication channel was used
- Which VoltSafe employee owns or made the latest touchpoint
- What needs attention today

This must use actual communication data, not placeholder values.

==================================================
2. DEFINE THE FOLLOW-UP LOGIC
==================================================

Use clear and deterministic rules.

Communication Status values:

- Never Contacted
- VoltSafe Owes Reply
- Waiting for Lead
- Follow-Up Due
- Follow-Up Overdue
- Recently Contacted
- Active Conversation
- No Response
- Dormant
- Closed / No Follow-Up Required

Suggested logic:

Never Contacted:
- No qualifying outgoing external communication exists

VoltSafe Owes Reply:
- Latest qualifying external communication is incoming
- No outgoing response exists after it

Waiting for Lead:
- Latest qualifying external communication is outgoing
- No incoming response exists after it
- Follow-up date has not yet arrived

Follow-Up Due:
- Next follow-up date is today

Follow-Up Overdue:
- Next follow-up date is before today
- Record is not closed, disqualified, lost, or marked no follow-up required

Recently Contacted:
- Outgoing communication occurred within the configurable recent-contact window

No Response:
- VoltSafe sent one or more communications
- No incoming response has been received
- Configurable number of days has passed

Dormant:
- No incoming or outgoing external communication within a configurable number of days

Active Conversation:
- Both incoming and outgoing communication have occurred within a configurable recent period

Store the configurable timing rules in Pipeline settings rather than hard-coding them.

Default settings:

- Recently contacted: within 7 days
- No response: 7 days after outgoing communication
- Dormant: no communication for 30 days
- Urgent stale lead: no communication for 14 days
- Follow-up due soon: within the next 3 days
