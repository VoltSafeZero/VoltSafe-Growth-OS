VoltSafe CMS — CEO Cockpit Phase 10: Upgrade Existing Board / Investor Pack Module

Goal:
Upgrade the existing Board / Investor Pack functionality instead of creating a duplicate module.

We already have some version of board/investor reporting in VoltSafe CMS. First audit what exists, then extend it carefully with the proposed CEO/CFO-only operating pack capabilities.

Do not create a parallel board-pack system if one already exists.

Context:
Earlier phases built:
- Phase 4: CEO Cockpit insights
- Phase 5: 1:1 notes and commitments
- Phase 6: CEO Action Queue
- Phase 7: Daily/Weekly CEO Briefing and Leadership Agenda
- Phase 8: Execution Intelligence / Drift Detection

Phase 10 should upgrade the existing board/investor reporting area so it can pull from these systems and produce a clean, reviewable executive operating pack.

Important permission rule:
This module must be restricted to CEO and CFO only.
CEO = Trevor
CFO = Scott Carlson

Normal admins should not get access unless they are explicitly CEO/CFO or already have a stronger existing board/capital permission that clearly maps to this use case.

2. Upgrade principle

Prefer these in order:

1. Extend existing services/routes/components.
2. Reuse existing tables if they cleanly fit.
3. Add missing columns with safe migrations if needed.
4. Add new supporting tables only when the existing model cannot support the feature.
5. Do not duplicate routes/pages/tables with a similar purpose.

If an existing board/investor module already has tables, do not create board_packs unless no equivalent table exists.

If an existing page already exists, upgrade that page instead of adding a second Board Pack page.

3. Backend upgrade

Add or extend a service layer for the existing module.

If no clean service exists, create:

server/services/board-pack.ts

Functions should support:

- buildBoardPack(actorUser, options)
- getBoardPack(packId, actorUser)
- listBoardPacks(actorUser, filters)
- createBoardPack(actorUser, input)
- updateBoardPack(packId, actorUser, patch)
- finalizeBoardPack(packId, actorUser)
- archiveBoardPack(packId, actorUser)
- buildBoardPackMarkdown(packId, actorUser)
- buildBoardPackExecutiveSummary(packId, actorUser)
- buildInvestorUpdateDraft(packId, actorUser)
- compareAgainstPreviousPack(actorUser, currentPackOrOptions)

If equivalent functions exist, upgrade them instead of replacing them.

No auto-send.
No external API calls.
No AI dependency required.
Draft functions return copyable text only.

4. Required upgraded pack sections

The upgraded pack must support these sections, whether stored as jsonb, rows, or existing structure:

A. Executive Summary
- 5 to 10 bullet summary
- what changed since last pack
- top wins
- top risks
- top CEO asks
- next 30-day priorities

B. Company Scorecard
Use existing CEO Cockpit / Execution Intelligence / Action Queue data:
- execution health score
- open blockers
- overdue commitments
- completed commitments
- stale tasks
- high-priority CEO actions
- weekly movement if available

C. Revenue / Pipeline
Use existing CRM/pipeline data:
- total pipeline
- weighted pipeline if available
- top opportunities
- stale opportunities
- expected close movement
- hot accounts
- customer/prospect momentum
- blockers to revenue

D. Capital / Funding
Only visible to CEO/CFO users with capital access.
Include:
- current raise status if available
- target raise amount if available
- investor pipeline
- active investor conversations
- committed/soft-circled capital if available
- grant/government funding opportunities
- next investor actions
- funding risks
- key asks

E. Product / Operations
Use local product/operations data:
- deployments/install workflows
- flagged deployments
- stalled workflows
- product risks
- operational blockers
- customer implementation risks

F. Team / Accountability
Use 1:1 notes, commitments, tasks, and action queue:
- team pulse summary
- open commitments
- missed commitments
- completed commitments
- owner load risks
- support needed
Use neutral language only.

G. Risks / Decisions Needed
Include:
- critical drift items
- recurring risks
- unresolved blockers
- capital risks
- revenue risks
- product risks
- decisions needed from board/investors/advisors

H. Wins / Momentum
Include:
- completed high-priority actions
- resolved blockers
- customer movement
- partner movement
- product milestones
- funding progress
- team wins

I. Next 30 / 60 / 90 Days
Structured plan:
- 30 days: urgent execution
- 60 days: growth and funding milestones
- 90 days: strategic outcomes

J. Board / Investor Asks
Clear asks:
- intros needed
- funding asks
- customer introductions
- hiring/advisor needs
- technical/compliance support
- government/grant support
- partnership support

or
