Plan the next shippable module after Zoom integration: Cortex Meeting Notes.

Reference product:
Spark Mail has Meeting Notes inside the mail client. It connects to calendar, prompts recording for scheduled meetings, allows ad-hoc recording, transcribes audio, summarizes, creates notes/action items, and keeps everything inside the mail/calendar workflow.

Goal:
Create the same architecture and flow inside VoltSafe CMS, integrated with our mail + calendar + CRM/task system.

Do NOT build yet unless asked. First produce a technical implementation plan.

Module name:
Cortex Meeting Notes

Core UX:
1. Scheduled meeting flow:
   - User has a calendar event.
   - VoltSafe detects upcoming meeting.
   - User sees prompt/button: “Record Meeting”
   - On click, recording starts.
   - Meeting session links automatically to calendar event.
   - After stop, AI generates:
     - Summary
     - Transcript
     - Notes
     - Decisions
     - Action items
     - Follow-up email draft
   - Outputs are linked back to:
     - calendar event
     - related email thread if available
     - CRM account/contact/lead/project if detected or selected

2. Ad-hoc flow:
   - User clicks “New Meeting Note” from Mail, Calendar, or global sidebar.
   - User enters optional meeting title.
   - User clicks Start.
   - App records/transcribes.
   - User clicks Stop.
   - AI generates same outputs.
   - User can manually link it to email/calendar/CRM records afterward.

3. Mail client integration:
   - Add “Meeting Notes” section in left sidebar similar to Spark.
   - Show meeting note list by date.
   - Each note has:
     - title
     - timestamp
     - summary preview
     - linked calendar event
     - linked email thread/contact/account if available
   - Detail view has tabs:
     - AI Summary
     - Transcript
     - Notes
     - Action Items
     - Follow-up

4. Calendar integration:
   - Upcoming calendar events should show a “Record Meeting” / “Create Meeting Note” button.
   - If a meeting has already been recorded, show “View Meeting Note.”
   - Meeting notes should link to calendar_events.id.
   - If the event has Zoom/Teams/Meet metadata, store meeting platform info.

5. CRM/task integration:
   - Allow extracted action items to become tasks.
   - Allow summary to be added to CRM timeline.
   - Allow note to link to:
     - account
     - contact
     - lead
     - opportunity
     - project
     - support ticket
   - Suggest links based on attendees/email addresses/company names.

Architecture requirements:
- Build as production-grade module, not a demo.
- Use additive-only schema.
- Do not touch Phase A.1 unless already completed.
- Do not modify existing PKs.
- Do not break mail/calendar inbox behavior.
- Respect existing permissions.
