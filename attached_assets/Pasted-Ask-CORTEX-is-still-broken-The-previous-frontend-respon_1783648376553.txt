Ask CORTEX is still broken. The previous frontend response-parsing fix was incomplete.

Current observed bug:
In Feed CORTEX > Ask CORTEX, I asked:

"What did you learn today?"

The response was:

"I don't learn or acquire new information in real-time. My knowledge is based on the information I was trained on, which is current only up to October 2023..."

This is wrong.

Expected behavior:
Ask CORTEX must answer based on Feed CORTEX ingested items stored in our app, especially today's ingested URLs/items. It should not return generic base-model boilerplate about not learning in real time.

Important distinction:
The previous fix solved frontend parsing of the API Response body.
This new failure proves the API is now returning text, but the RAG/retrieval path is not being used correctly, or the prompt/context passed to the model is empty.

Investigate and fix the real Ask CORTEX retrieval pipeline.

Likely root causes to check:
1) Ask Cortex endpoint is calling the LLM without retrieved context.
2) Retrieval query returns zero records for "today" due to date/timezone mismatch.
3) Feed ingestion saves records, but Ask Cortex searches a different table/source.
4) Ingested feed items are visible in UI but not indexed/embedded/searchable.
5) Backend response fallback is using a generic LLM answer when retrieval is empty.
6) Prompt does not force the model to answer from Cortex memory/context.
7) The Ask Cortex route may still be using an old/general chat endpoint instead of Feed Cortex RAG.
8) Today's ingested records may have intel_type/source/status values that the retrieval filter excludes.
9) Response contract may be fixed, but backend answer generation is not grounded.
