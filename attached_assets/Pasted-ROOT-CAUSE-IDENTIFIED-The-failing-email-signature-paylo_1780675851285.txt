ROOT CAUSE IDENTIFIED

The failing email signature payload contains a FULL HTML DOCUMENT embedded inside the email body:

<!DOCTYPE html>
<html>
<head>...</head>
<body>
  ...signature...
</body>
</html>

The request payload is only ~2.9 KB, so this is NOT a payload-size issue.

Evidence:
- Email sends successfully with no signature.
- Email fails with HTML signature.
- POST /api/gmail/send returns:
  403 Forbidden
  Content-Type: text/html
- Response body:
  <!doctype html>
  <title>403</title>
  403 Forbidden
- Payload inspection shows full-document HTML inside the signature.

This strongly indicates the Replit proxy/WAF is rejecting the request content before the application processes it.

GOAL

Fix this permanently for:
- existing users
- future users
- imported signatures
- pasted signatures
- edited signatures
- compose/send flows

WITHOUT converting signatures to plain text.

All HTML signature formatting, tables, links, images, and styling must remain intact.

REQUIRED CHANGES

1. Create a shared signature normalizer

Create:

server/services/signature-normalizer.ts

Function:

normalizeSignatureHtml(html: string): string

Strip:

- <!DOCTYPE ...>
- <html>
- </html>
- <head>
- </head>
- <body>
- </body>
- <meta ...>
- <title ...>

Preserve:

- tables
- spans
- divs
- inline styles
- links
- safe HTTPS images
- formatting
- layout

The output should always be a clean HTML fragment.

Example:

INPUT:

<!DOCTYPE html>
<html>
<head></head>
<body>
<table>...</table>
</body>
</html>

OUTPUT:

<table>...</table>

2. Apply normalization everywhere

Apply normalizeSignatureHtml():

A) Signature creation
B) Signature editing
C) Signature import
D) Signature paste/upload
E) Signature preview
F) Compose rendering
G) Frontend send payload assembly
H) Backend send route

No signature should ever reach the send pipeline containing:

<!DOCTYPE
<html
<head
<body

3. Frontend protection

Before JSON.stringify(payload):

const safeSig = normalizeSignatureHtml(signatureHtml)

Add diagnostics:

console.log("[FINAL FETCH ABOUT TO SEND]", {
  containsDoctype,
  containsHtmlTag,
  containsHeadTag,
  containsBodyTag,
  jsonSizeBytes
})

All four booleans MUST be false.

4. Backend protection

Before MIME generation:

body = normalizeSignatureHtml(body)

Log:

[gmail-send-normalized] {
  removedDoctype,
  removedHtml,
  removedHead,
  removedBody
}
