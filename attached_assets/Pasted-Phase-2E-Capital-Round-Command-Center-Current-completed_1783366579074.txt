5. Weighted pipeline calculation

Create a transparent weighted pipeline helper.

Suggested default weights:

- Wired: 100%
- Committed: 95%
- Verbal Commit: 80%
- Diligence: 60%
- Soft-Circled: 45%
- Interested: 25%
- Target: 10%
- Stalled: 5%
- Passed: 0%

Weighted amount should use:
- committed amount if available
- target cheque amount if no committed amount
- cheque capacity or stage estimate if needed

Return:
- raw target pipeline
- weighted pipeline
- committed/wired amount
- soft-circled amount
- remaining gap
- confidence band
