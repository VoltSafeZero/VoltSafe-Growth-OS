Do not work on Accounts, Contacts, CRM list views, group DMs, Guest Currents, external collaborators, slash commands, workflow automation, notification preferences, typing indicators, or unrelated task features.

Verify that Channel Management is secure, stable, polished, and regression-free.

This audit should verify the full feature.

Schema / migration checks

Verify:

1. current_channels has required columns:
    * description or equivalent
    * archived_at
    * archived_by
    * updated_at if used
2. Migration is idempotent.
3. Existing channel rows remain valid.
4. Existing archived channels remain valid.
5. New columns do not break existing channel queries.
6. Slug/name uniqueness is enforced safely.

POST /api/current/channels

Verify:

1. Requires authentication.
2. Requires admin permission.
3. Rejects non-admin users.

9. Returns created channel.
10. New channel appears in sidebar after refetch.

Verify:

1. Requires authentication.

3. Rejects non-admin users.
4. Rejects missing channel.
5. Rejects empty/whitespace-only name if name is updated.
6. Normalizes slug safely when name changes.
7. Rejects duplicate active slug.
8. Allows description update.
9. Preserves channel id.
10. Existing messages remain linked and visible.
11. Sidebar updates after edit.

POST /api/current/channels/:id/archive

Verify:

1. Requires authentication.
2. Requires admin permission.
3. Rejects non-admin users.
