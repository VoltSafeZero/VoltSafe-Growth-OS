Phase 2 — CRM matching utility
Create or reuse a backend utility that matches calendar events to CRM records.

Matching rules:
1. External attendee email exact match to Contact/Person = highest confidence
2. External attendee domain match to Account domain/website/email domain = high confidence
3. Event title contains exact Account/Lead name = medium confidence
4. Event title fuzzy match = low confidence only if safe
5. Ignore common domains like gmail.com, outlook.com, yahoo.com, icloud.com unless there is an exact contact/person email match
6. Always ignore @voltsafe.com as external CRM target
7. Return match reason and confidence

Suggested return shape:
crmMatches: [
  {
    entityType: "account" | "lead" | "contact" | "person",
    entityId: string,
    entityName: string,
    confidence: "high" | "medium" | "low",
    reason: string,
    matchedOn: "attendee_email" | "attendee_domain" | "event_title"
  }
]

Implementation options:
- Preferred: include crmMatches in GET /api/calendar/events response.
- Acceptable: create GET /api/calendar/events/:id/context if cleaner.
- Reuse existing CRM context route if already built and stable.
