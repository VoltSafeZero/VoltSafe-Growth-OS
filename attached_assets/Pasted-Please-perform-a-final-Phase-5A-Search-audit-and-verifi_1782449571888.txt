Please perform a final Phase 5A Search audit and verification pass for Currents.

Do not add AI summaries, Guest Currents, direct messages, slash commands, external collaborators, or any new feature yet.

Goal

Confirm that Currents Search is safe, accurate, polished, and fully verified after the recent fixes to:

1. Record search deep-links
2. Record feed search keyword highlighting

Audit scope

Audit only:

* /api/current/search
* /current search UI
* Record Currents inline search
* Search result deep-links
* Search result snippets/highlighting
* Deleted-message safety
* Channel/record isolation
* Existing Currents regressions caused by search

Backend checks

Verify GET /api/current/search:

1. Requires authentication.
2. Rejects or safely handles missing/empty q.
3. Uses parameterized queries.
4. Enforces a limit cap.
5. Handles invalid scope safely.
6. Handles invalid channel safely.
7. Handles invalid objectType/objectId safely.
8. scope=all searches channel + record Currents.
9. scope=channel returns only channel messages.
10. scope=record returns only record messages.
11. channel=general returns only #general.
12. objectType=account&objectId=ID returns only that Account’s Currents.
13. Thread replies are searchable.
14. Top-level messages are searchable.
15. Attachment filenames are searchable if implemented.

Deleted data safety

Verify:

1. Soft-deleted message bodies do not appear in search.
2. Soft-deleted thread replies do not appear.
3. Attachment filenames from deleted messages do not appear.
4. Search snippets never expose redacted/deleted body text.
5. Search result links do not point to deleted messages unless intentionally handled.
6. Deleted-message attachment redaction from Phase 4A still works.

Deep-link checks

Verify search result links:

1. Channel top-level result:
    * /current?channel=general&message=MESSAGE_ID
2. Channel thread reply result:
    * /current?channel=general&thread=ROOT_ID&message=REPLY_ID
3. Account record result:
    * Opens Account page
    * Activates/scrolls to Currents
    * Highlights target message if supported
4. Contact record result:
    * Opens Contact page
    * Activates/scrolls to Currents
    * Highlights target message if supported
5. Opportunity record result:
    * Opens Opportunity page
    * Activates/scrolls to Currents
    * Highlights target message if supported
6. Lead record result:
    * Uses the corrected Lead route:
        * /opportunities?selected=LEAD_ID&tab=current&message=MESSAGE_ID
    * Opens the Lead detail/dialog
    * Shows Currents
    * Highlights target message if supported
7. Thread result inside record Currents:
    * Opens the correct record
    * Opens the thread panel if supported
    * Highlights the reply if supported

1. Search sidebar item appears cleanly.
2. Search view opens correctly.
3. Debounced input works.
4. Loading state looks polished.

Isolation checks

Verify:

1. Channel search does not return record messages.
2. Record search does not return channel messages.
3. Account search does not return Contact/Lead/Opportunity messages.
4. Lead search does not return Opportunity messages with the same numeric ID.
5. Search result links do not cross into the wrong entity.
6. Currents search does not show unrelated CRM attachment records.
