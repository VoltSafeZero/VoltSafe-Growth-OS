AI summary action item task

Must store:

* sourceContext if exact channel/record context exists
* summaryContext = "currents_summary"
* source scope:
    * channel / thread / record if available
* channelSlug if summary came from a channel
* objectType/objectId if summary came from a record
* messageId/threadRootId if summary came from a thread or exact source
* owner/task/due from the action item where available

If exact message context is unavailable, do not fabricate one. The task drawer should show:

with no broken link.
