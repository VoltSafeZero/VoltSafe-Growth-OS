Build a new dashboard widget called:

Needs Reply — High Engagement

Objective:
Show the highest-engagement email threads that currently require a reply from us.

This should become a daily action queue, not an analytics widget.

==================================================
SOURCE OF TRUTH
==================================================

IMPORTANT:

Use the exact same engagement source used by InboxSignalBadge and the corrected getThreadEngagementFull() implementation.

Do NOT create a new engagement calculation system.

The widget must match the engagement counts visible in the inbox list.

==================================================
BACKEND
==================================================

Add endpoint:

Return:

{

      subject: string,

      snippet: string,

      opensCount: number,

      routeTarget: string

  ]
}

==================================================
REPLY LOGIC
==================================================

Thread should appear when:

- Recipient engaged
- Thread is not closed
- Thread is not done
- Thread is not marked No Reply Needed
- Latest meaningful action requires response from us

Exclude:

- Spam
- Trash
- Archived completed threads
- Done
- No Reply Needed

==================================================
SCORING
==================================================

Score:

Open = 1
Link click = 3
CTA click = 5
Video/demo click = 8
Inbound reply awaiting our response = 10

Final score:

engagementScore

Sort descending by default.
