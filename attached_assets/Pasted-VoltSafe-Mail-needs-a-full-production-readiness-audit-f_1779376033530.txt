VoltSafe Mail needs a full production-readiness audit focused on trust, reliability, multi-user safety, and UX confidence before broader team rollout.

This is NOT a feature audit.
This is a mail integrity + operational reliability audit.

Goal:
Ensure VoltSafe Mail behaves as a trustworthy Gmail operational layer for ALL users — not just trevor@voltsafe.com.

Please perform the following deep audit and produce a structured report with findings, risks, and recommended fixes prioritized by severity and engineering effort.

==================================================
PHASE 1 — MAIL LIFECYCLE & STATE INTEGRITY
==================================================

Audit the entire lifecycle of:
- Drafts
- Scheduled emails
- Sends
- Replies
- Forwards
- Sync/import
- Failed sends
- OAuth reconnect flows

Verify every message always exists in ONE authoritative state:

- Draft
- Scheduled
- Sending
- Sent
- Failed
- Archived
- Deleted

A message must NEVER silently disappear.

Specifically verify:

1. Draft lifecycle
- survives refresh
- survives tab close/reopen
- survives OAuth refresh
- survives API timeout
- survives reconnect
- survives duplicate tabs
- local vs Gmail source-of-truth behavior

2. Send lifecycle
- optimistic UI vs confirmed send behavior
- when Sent state is committed
- duplicate send prevention
- timeout handling
- retry handling
- Gmail API error handling (429, 401, 403, 5xx)

3. Scheduled send lifecycle
- exact scheduler flow
- when scheduled rows are removed
- whether Gmail confirmation is required before deletion
- failed scheduled send handling
- retry queue existence
- timezone handling
- local vs UTC conversion

4. Sync lifecycle
- Gmail vs local DB source-of-truth
- conflict resolution
- label reconciliation
- deleted email reconciliation
- incremental sync behavior
- polling/websocket behavior
- stale cache handling

5. OAuth lifecycle
- token refresh
- revoked access behavior
- reconnect flow
- partial permission failures
- account switching safety

==================================================
PHASE 2 — MULTI-USER SAFETY & ISOLATION
==================================================

This is CRITICAL.

Verify ALL mail state is fully isolated per user.

Audit:
- OAuth token isolation
- polling isolation
- websocket isolation
- local cache isolation
- Zustand/React store isolation
- scheduler isolation
- draft isolation
- compose state isolation
- account switching behavior
- logout/login behavior
- stale cache persistence

Specifically test:
User A logout → User B login

Verify:
- no inbox bleed-through
- no stale drafts
- no cached threads
- no stale avatars/accounts
- no incorrect compose sender identity

This must be treated as a security-critical audit.
