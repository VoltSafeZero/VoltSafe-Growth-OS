/current sidebar/view checks

Verify:

1. Structured sidebar button appears in a sensible position.
2. Button label/icon look consistent with Search and Mentions.
3. Clicking Structured opens the structured items view.
4. Returning to Channels, Mentions, or Search works cleanly.
5. The current selected channel remains stable when switching views.
6. The view does not break unread counts.
7. The view does not auto-scroll weirdly.
8. Dark mode styling is polished.

Scope toggle checks

Verify if implemented:

1. Current channel scope works.
2. All Currents scope works.
3. Toggle label is clear.
4. Switching scope refreshes results correctly.
5. No stale results remain when switching from All to current channel.
6. Channel-specific results do not show unrelated record items unless intentionally included.
7. All-Currents view clearly labels the source context.

Filter checks

Verify filters:

* All
* Decisions
* Risks
* Requirements

Check:

1. All shows all item types.
2. Decisions shows only decisions.
3. Risks shows only risks.
4. Requirements shows only requirements.
5. Filter selected state is obvious.
6. Changing filters updates results without reload.
7. Empty states are specific:
    * “No decisions marked yet.”
    * “No risks marked yet.”
    * “No requirements marked yet.”
8. Filters do not reset unexpectedly when switching views unless intentional.

Item card/row checks

* Type badge
* Message preview
* Original author
* Marked by / created by if available
* Created date
* Source context
* View in Currents action

Verify:

1. Long message previews truncate cleanly.
2. Deleted message text is not exposed.
3. Missing author/createdBy data does not crash UI.
4. Source labels are readable:
    * #general
    * Account Currents
    * Lead Currents
5. Item type colors match badges from messages.
6. Cards look good in dark mode.
7. Cards do not feel like developer debug output.

Deep-link checks

Click View in Currents for each available source type.

Verify:

Channel message

Expected:

/current?channel=CHANNEL_SLUG&message=MESSAGE_ID

Should open correct channel and highlight/scroll to message if supported.

Channel thread reply

Expected:

/current?channel=CHANNEL_SLUG&thread=THREAD_ROOT_ID&message=MESSAGE_ID

Should open correct channel, thread panel, and reply/root context.

Account record message/thread

Expected:

/accounts/OBJECT_ID?tab=current&message=MESSAGE_ID

and with thread param when applicable.

Contact record message/thread

Use existing contact route.

Opportunity record message/thread

Use existing opportunity route.

Lead record message/thread

Expected:

/opportunities?selected=LEAD_ID&tab=current&message=MESSAGE_ID

and with thread param when applicable.

Check that record links navigate correctly even from /current all-Currents structured view.
