Build Recipient-Level Engagement Tracking (HubSpot/Salesforce/Klaviyo Style)

Objective:

Move VoltSafe Mail from message-level tracking to recipient-level tracking so we know exactly WHICH person opened, clicked, viewed a demo, or engaged with an email.

Current Problem:

Today engagement is tracked primarily at the message/thread level.

Example:

TO: marina@tmv.vc
CC: soraya@tmv.vc
CC: scott@voltsafe.com

Current analytics:

Opened 14x
3 Clicks

This is not actionable because we do not know:

- Which recipient opened
- Which recipient clicked
- Whether the engagement was internal
- Whether the primary recipient engaged
- Whether a decision maker engaged

Goal:

Provide HubSpot/Salesforce/Klaviyo-style recipient-level engagement.

==================================================
PHASE 1 — DATA MODEL
==================================================

Create recipient-level tracking.

Add table:

email_recipients

Fields:

id
gmail_message_id
gmail_thread_id

recipient_email
recipient_name

recipient_type
('to','cc','bcc')

is_primary_recipient
boolean

is_internal
boolean

tracking_token
unique

created_at

==================================================
TRACKING TOKENS
==================================================

Every recipient receives a unique token.

Example:

marina@tmv.vc
→ token_abc123

soraya@tmv.vc
→ token_def456

scott@voltsafe.com
→ token_ghi789

No shared tracking tokens.

No shared tracking pixels.

No shared click tracking.

==================================================
PHASE 2 — OPEN TRACKING
==================================================

Tracking pixel URLs must become recipient-specific.

Current:

/track/open/{messageId}

Replace with:

/track/open/{trackingToken}

When pixel fires:

1. Resolve recipient
2. Resolve recipient email
3. Resolve recipient type
4. Create engagement event

Store:

recipient_email
recipient_type
tracking_token

is_internal

==================================================
PHASE 3 — CLICK TRACKING
==================================================

All tracked links become recipient-specific.

Current:

/track/click/{token}

Replace with:

/track/click/{trackingToken}/{linkId}

When clicked:

Store:

recipient_email
recipient_type
tracking_token

destination_url

is_internal

==================================================
PHASE 4 — CTA TRACKING
==================================================

Apply the same model to:

- Signature CTA clicks
- Demo video clicks
- Webinar clicks
- Document clicks
- Meeting booking clicks

All events must resolve to a specific recipient.

==================================================
PHASE 5 — INTERNAL FILTERING
==================================================

Internal domains:

@voltsafe.com
@voltsafemarine.com

Add:

is_internal

to all engagement event tables.

Rule:

Internal engagement never contributes to:

- Open counts
- Click counts
- Intent scores
- Hot lead scores
- Widgets
- Dashboards
- Reply queues

Required filter everywhere:

is_internal IS NOT TRUE
