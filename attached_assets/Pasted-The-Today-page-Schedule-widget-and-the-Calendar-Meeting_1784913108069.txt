The Today page Schedule widget and the Calendar & Meetings page are currently using different event sets. This is a bug.

Treat Calendar & Meetings as the canonical source of truth.

==================================================
GOAL
==================================================

The Today page Schedule section must display the exact same meetings/events that appear in Calendar & Meetings for the selected day.

There must never be two independent calendar pipelines.

==================================================
REQUIRED ARCHITECTURE
==================================================

There must be a single unified calendar event service.

Every consumer must use it:

- Calendar & Meetings
- Today Schedule
- Upcoming Meetings
- Meeting Recorder
- Mission Control
- Daily Execution
- notifications
- reminders
- AI scheduling

No component may independently query Google Calendar, Microsoft, or other providers if the unified service already exists.

==================================================
INVESTIGATE
==================================================

Determine why Today differs from Calendar & Meetings.

Possible causes include:

• different API endpoint
• different event query
• different filters
• different selected calendars
• stale cache
• missing recurring expansion
• different timezone handling
• excluding all-day events
• duplicate removal logic
• different permissions
• separate event normalization
• different date window
• using cached vs live data

Find the root cause.
