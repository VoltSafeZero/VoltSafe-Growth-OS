Implementation Phase 1 — Add “Now / Next” strip

Add a compact card/strip near the top of Calendar page, preferably above the day grid or at the top of the sidebar.

The strip should show one primary recommendation and one secondary recommendation.

Recommendation priority order:

1. Join current meeting
    If current time falls within a calendar event:

* Show: “Now: [Meeting Title]”
* Show meeting time range.
* If meetingUrl exists, show “Join”
* If CRM context exists, show “Open Prep”
* Do not show for all-day events.
* Do not show team overlay events.

2. Prep for next external/CRM meeting
    If next meeting starts within 60 minutes and has external attendees or CRM match:

* Show: “Next: Prep for [Meeting Title]”
* Show start time.
* Action: “Open Prep”

3. Capture outcome for recently finished meeting
    If a meeting ended within the last 2 hours, has external/CRM context, and no outcome saved:

* Show: “Capture outcome: [Meeting Title]”
* Action: “Add Outcome”

4. Work overdue/due follow-up task
    If no meeting action is urgent:

* Show highest priority overdue/due task.
* If task is unscheduled, action: “Schedule”
* If task is linked to CRM, show linked type badge.

5. Use open focus window
    If there is an open window of at least 30 minutes:

* Show: “Open focus window: [time range]”
* Action: “Schedule Task”

6. All clear
    If nothing needs action:

* Show: “You’re clear for now.”
* Secondary: next meeting or next task if available.

Implementation Phase 2 — Action buttons

Actions should reuse existing handlers:

* Join → opens meetingUrl in new tab.
