2. Automation State Machine Audit

Audit:

* startCampaignAutomation
* pauseCampaignAutomation
* resumeCampaignAutomation
* stopCampaignAutomation
* getCampaignAutomationStatus

Verify:

* start is blocked unless compliance_status === preflight_passed
* start is blocked with zero recipients
* start is blocked with zero campaign emails
* start is blocked for archived/completed campaigns
* start is idempotent or returns a clean 409 if already active
* pause only works from active/scheduled

* stop terminally disables automation

* archived campaigns cannot be automated
* all state transitions create campaign_events
* state transitions do not corrupt current_step
* state transitions do not reset recipients incorrectly

3. Scheduling Logic Audit

Verify:

* delay_days is consistently relative to sequence_started_at

* future steps are not sent early
* missed due steps send on next tick
* next_step_due_at updates correctly after each step
* recipient sequence_completed_at is set only after final step
* campaign automation_completed_at is set only when all recipients are terminal
* timezone field is either used correctly or clearly reserved for future use
* automation_timezone does not create misleading behavior if unused
