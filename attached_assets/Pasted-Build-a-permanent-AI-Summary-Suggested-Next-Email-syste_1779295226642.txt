Build a permanent AI Summary + Suggested Next Email system for VoltSafe CMS.

PRIMARY OBJECTIVE
VoltSafe CMS already centralizes historical and current communication, notes, contacts, documents, CRM activity, and linked emails into Leads, Accounts, and Contacts.

The missing layer is an AI operational intelligence system that continuously understands and summarizes everything into a simple, always-current briefing.

Users should NOT need to read months or years of historical emails and notes to understand:
- relationship history
- current status
- key people
- next steps
- blockers
- opportunities
- context

Instead, every LEAD, ACCOUNT, and CONTACT should automatically contain:
1. An always-current AI Summary (“Coles Notes” operational briefing)
2. AI-generated Suggested Next Email functionality

This should become a foundational productivity layer across VoltSafe CMS.

==================================================
GLOBAL REQUIREMENT — AUTO-GENERATE FOR ALL EXISTING RECORDS
==================================================

CRITICAL REQUIREMENT:

This system must automatically generate AI Summaries for:
- ALL existing Leads
- ALL existing Accounts
- ALL existing Contacts

NOT just newly created records.

On deployment:
1. Backfill summaries for every existing CRM entity.
2. Run safely in batches/background jobs.
3. Never lock or freeze the app.
4. Never block user requests.
5. Track progress/status.
6. Skip unchanged entities intelligently using hashing/fingerprinting.

After deployment:
- All newly created Leads/Accounts/Contacts should automatically get summaries.
- All existing summaries should stay continuously updated.

==================================================
AUTO-REFRESH / STALE HANDLING
==================================================

The AI Summary must continuously stay current.

Any meaningful CRM update should:
1. Mark summary stale
2. Trigger safe background regeneration

Events that MUST mark stale:
- New linked email
- Email unlinked
- New note
- Note edited
- Note deleted
- Contact linked/unlinked/edited
- Document linked/uploaded/deleted
- Lead/Account/Contact field updated
- Stage/status changed
- Action item created/edited/completed/deleted
- Lead converted to Account
- Manual merge/link operations
- Email sync/import
- Gmail sync updates

Requirements:
- Background-safe
- Non-blocking
- Never slow page loads
- Never freeze UI
- Never create regeneration loops

Use:
- source_hash or equivalent fingerprinting
to prevent unnecessary regeneration.
