Backend requirements

If missing, update the existing reaction routes so they work for:

* channel messages
* 1:1 DM messages
* group DM messages

Rules:

1. Requires authentication.
2. Message must exist.
3. Deleted messages cannot be reacted to.
4. For channel messages:
    * existing channel/archived rules remain unchanged.
5. For DM/group DM messages:
    * current user must be an active member of the conversation.
    * users who left a group DM cannot react.
    * non-members cannot infer message/conversation details.
6. Add reaction is idempotent.
7. Remove reaction only removes current user’s reaction.
8. Reaction counts aggregate correctly.
9. Current user’s own reaction state is returned correctly.
10. No duplicate reactions from same user/message/emoji.
11. No SQL injection through emoji/message id.
