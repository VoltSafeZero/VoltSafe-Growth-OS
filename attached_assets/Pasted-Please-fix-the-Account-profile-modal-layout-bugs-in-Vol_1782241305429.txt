In the Account modal/profile popup, there are 3 header tabs:

* Overview
* People & Pipeline
* Activity

When I click the Activity tab on the far right, the right side of the modal/page content gets cut off horizontally. This should never happen.

Required behavior:

* Switching between Overview, People & Pipeline, and Activity must not change the modal width unexpectedly.
* The Activity tab content must stay fully inside the modal viewport.
* No horizontal clipping.
* No content disappearing off the right edge.
* No need for the user to scroll sideways to see the full tab content.
* The modal should remain responsive at desktop and smaller widths.

Please audit:

* Account modal container width
* Tab header layout
* Activity tab content wrapper
* Any overflow-x, fixed width, min-width, transform, absolute positioning, or grid/flex rules causing the Activity pane to exceed the modal boundary

Likely fix:

* Ensure the modal body uses max-width: 100%
* Ensure tab panels use width: 100%
* Add min-width: 0 to flex/grid children where needed
* Use overflow-x: hidden only on the correct wrapper, not as a lazy cover-up that hides useful content
* Make Activity content wrap instead of forcing the modal wider
