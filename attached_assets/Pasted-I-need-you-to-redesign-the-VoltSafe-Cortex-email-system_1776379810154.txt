CRM LINKING LOGIC
==================================================

Build automatic email-to-CRM linking using this priority order:

1. Exact email address match to existing contact
2. Exact email address match to lead
3. Exact domain match to account/company domain
4. Existing thread already linked to a CRM object
5. Manual override by user
6. AI-assisted fallback suggestion only if confidence is low

For every email/thread, store:
- primary linked object
- all linked objects
- confidence score
- why it was linked

Examples:
- marina GM email -> account + contact + opportunity
- investor email -> lead or partner depending on type
- support issue -> account + ticket
- quote thread -> account + quote + opportunity
