Context

Root cause found:

MessageActionBar referenced hasBody, but hasBody was listed only in the TypeScript props type and was missing from the runtime function destructuring. TypeScript erased the type, so runtime JavaScript threw:

ReferenceError: hasBody is not defined

Fix applied:

function MessageActionBar({
  isOwn,
  isAdmin,
  isPinned,
  isArchived,
  hasBody,
  onReact,
  ...
})

E2E test after the fix confirmed /current loads with channel list, message feed, and composer visible.
