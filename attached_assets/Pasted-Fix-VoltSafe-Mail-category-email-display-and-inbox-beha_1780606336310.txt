PART 2 — Make Gmail category emails appear in Inbox

Current issue:
Messages with labels like CATEGORY_UPDATES, CATEGORY_PROMOTIONS, CATEGORY_SOCIAL, CATEGORY_FORUMS are being treated as separate from Inbox even when they should be visible in the inbox.

Required behavior:
VoltSafe Inbox should include:
- messages with INBOX label
- plus Gmail category messages that are not sent/draft/spam/trash/archived
- plus unread/category messages that Gmail users would reasonably expect to see in their inbox

Exclude from Inbox:
- SENT
- DRAFT
- SPAM
- TRASH
- explicitly archived messages
- deleted messages
- scheduled/pinned special views unless explicitly selected

Important Gmail nuance:
Some category messages may not have the INBOX label in the local database even though users expect them in the inbox. Do not rely only on labels.includes("INBOX") to determine inbox visibility.

Implement a shared helper, for example:
isInboxVisibleMessage(labels, message)

Suggested logic:
Inbox-visible if:
- has INBOX label
OR
- has any Gmail category label:
  - CATEGORY_PERSONAL
  - CATEGORY_SOCIAL
  - CATEGORY_PROMOTIONS
  - CATEGORY_UPDATES
  - CATEGORY_FORUMS
AND NOT:
  - SENT
  - DRAFT
  - SPAM
  - TRASH
  - archived flag true, if exists
  - deleted flag true, if exists

Then replace all hardcoded INBOX-only filters used for:
- Inbox message fetch
- Smart Inbox grouping
- mailbox counts
- unread counts
- default “All Inboxes” view
- search result visibility, if search is scoped to inbox

Do not duplicate this logic in multiple places.
