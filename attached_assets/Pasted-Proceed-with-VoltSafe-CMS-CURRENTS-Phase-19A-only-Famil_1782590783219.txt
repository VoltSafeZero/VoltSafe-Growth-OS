Goal

Make CURRENTS feel more familiar to the VoltSafe team coming from Slack, with the smallest possible learning curve.

This phase should focus on layout, density, visual hierarchy, and navigation familiarity only.

Why

The VoltSafe team is used to Slack. CURRENTS is now powerful, but it should feel more familiar so users naturally switch over.

Use Slack-like layout patterns where helpful, while keeping VoltSafe’s own premium Growth OS identity.

1. Compact CURRENTS sidebar density

Make the internal CURRENTS sidebar feel closer to Slack’s density.

Polish:

* reduce channel row vertical padding slightly
* reduce DM row vertical padding slightly
* keep selected row very clear
* keep unread state visible
* align #, lock, unread, muted, and presence indicators cleanly
* make section headers tighter and more scannable
* allow more channels/DMs to fit vertically
* keep text readable
* avoid making the sidebar feel cramped

Expected feel:

* more “work cockpit”
* less empty space
* faster scanning
* familiar to Slack users

Do not change the main app sidebar.

2. Add Slack-style top tab row

Add a horizontal tab/action row below the channel/DM header.

For channels, show:

* Messages
* Files
* Pins
* Tasks
* Structured
* Members

For DMs/group DMs, show:

* Messages
* Files
* Tasks
* Search

This can be mostly UI/navigation polish.

Use existing functionality where available:

* Messages = current feed
* Files = can open/search/filter existing attachments if already available; if no full view exists yet, use a disabled or “Coming soon” style only if necessary
* Pins = existing pinned messages panel/list if available
* Tasks = existing Create Task/source task flow if available; otherwise link to existing task context only if safe
* Structured = existing structured items view
* Members = existing participants/member dialog
* Search = existing CURRENTS search view

Do not build a full new Files backend in this phase.

The tab row should feel familiar but VoltSafe-branded:

* compact
* subtle active underline
* icons if already available
* works in light/dark mode
* no crowding
