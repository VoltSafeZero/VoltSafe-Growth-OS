==================================================
EXTERNAL USER RULE
==================================================

External status must not itself override an explicitly granted module permission.

Correct:

external + Leads View Only
→ may open Leads
→ may view allowed lead data
→ cannot edit, export, or download unless separately allowed

external + Leads View & Edit
→ may open and edit Leads, subject to record-level restrictions

external + Leads No Access
→ Access Restricted

Incorrect:

external
→ always Access Restricted regardless of assigned permission
