Desired behavior

DM list ordering

DM conversations should sort newest activity first:

1. Most recent last_message_at
2. Conversations with no messages should appear after active DMs
3. Stable fallback sort by conversation id or created_at

Unread count

For each DM:

1. Count messages after the current user’s last_read_message_id
2. Do not count the current user’s own messages as unread
3. Count text-only messages
4. Count text + attachment messages
5. Count attachment-only messages
6. Deleted messages should not count as unread if they are hidden/redacted
7. Opening a DM should mark it read
8. Sending a DM should not create unread count for the sender
9. Receiving a DM should increment unread count until opened

Read behavior

When a user opens a DM:

1. Mark read to the latest visible message id
2. Read state should never move backwards
3. Reopening the same DM should not create extra writes if already read
4. Switching between DMs should mark the selected DM read once messages load
5. Deep-linking to /current?dm=ID should mark read after messages load
6. Poll/refetch should not cause badge flicker

Sidebar preview

DM row preview should be sensible for:

1. Text-only message
2. Text + attachment message
3. Attachment-only message: 📎 Attachment
4. Deleted message: avoid showing deleted content
5. Mention syntax: display @Name, not raw markdown mention token
6. Long preview: truncate cleanly

Total unread badge

The Currents module total unread should include:

1. Channel unread
2. DM unread

It should not double-count or include current user’s own messages.
