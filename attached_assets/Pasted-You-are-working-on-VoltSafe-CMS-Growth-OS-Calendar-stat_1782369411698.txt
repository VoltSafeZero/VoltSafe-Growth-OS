Phase 1 — Make Team Calendars honest

Phase 2 — Backend free/busy route
Create or update a route:

GET /api/calendar/team-availability?date=YYYY-MM-DD&userIds=user1,user2,...

Behavior:
- Authenticated only.
- Current user can request availability for selected teammates.
- For each teammate:
  - If teammate has valid Google Calendar connection with calendar scope, query Google freebusy.
  - If not connected, return status: "not_connected".
  - If token expired/reconnect needed, return status: "reconnect_required".
  - If permission unavailable, return status: "unavailable".
- Return only busy blocks, never event titles/descriptions/attendees.
- Use the selected date in the user’s timezone.
- Include start/end ISO timestamps.
- Include userId, userName, email, status, busyBlocks.

Suggested response shape:
{
  date: "2026-06-24",
  timezone: "America/Vancouver",
  users: [
    {
      userId: "...",
      name: "Sana",
      email: "sana@voltsafe.com",
      status: "available" | "not_connected" | "reconnect_required" | "unavailable",
      busyBlocks: [
        { start: "...", end: "..." }
      ]
    }
  ]
}

Use Google Calendar freebusy endpoint if available.
Do not pull full events for teammates.

Phase 3 — Frontend overlay
Update the existing Calendar page:
- When teammate checkbox is selected, call team availability route.
- Show loading state per teammate or global small spinner.
- Render busy blocks in the day view as subtle background overlays or side-by-side lane blocks.
- Label only teammate name and “Busy”.
- Do not show event titles.
- If multiple selected teammates are busy at the same time, visually stack or combine without making the calendar unreadable.
- If a teammate is not connected, show small status text in the Team Calendars card.

Phase 4 — Available windows
Add a simple “Suggested Openings” section under Team Calendars or below the day grid.

For selected users, calculate shared open windows:
- Based on current user’s visible events + selected teammates’ busy blocks.
- Workday default: 8:00 AM–6:00 PM local time.
- Minimum meeting duration default: 30 minutes.
- Return/display top 3 open windows.

Example:
Suggested Openings
- 10:30–11:00 AM
- 1:00–1:45 PM
- 3:30–4:30 PM

If no teammates selected:
Show:
“Select teammates to find shared openings.”

If no common openings:
Show:
“No shared openings found today.”

Keep this calculation simple and deterministic.
