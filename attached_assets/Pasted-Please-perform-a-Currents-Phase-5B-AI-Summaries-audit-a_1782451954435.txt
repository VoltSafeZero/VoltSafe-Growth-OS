Please perform a Currents Phase 5B AI Summaries audit and polish pass only.

Do not add Guest Currents, direct messages, slash commands, external collaborators, workflow automation, or any unrelated CRM features yet.

Goal

Verify that Currents AI Summaries are safe, useful, reliable, and polished across:

1. Channel Currents summaries
2. Thread summaries
3. CRM Record Currents summaries
4. Summary UI states
5. Deleted-data safety
6. Existing Currents regressions

Audit scope

Audit only:

* POST /api/current/summary
* current-summary-panel.tsx
* Channel summary UI in /current
* Thread summary UI in /current
* Record Currents summary UI
* Existing OpenAI compatibility/test updates

Backend checks

Verify POST /api/current/summary:

1. Requires authentication.
2. Rejects invalid scope.
3. Validates required fields for each scope:
    * channel
    * messageId
    * objectType
    * objectId
4. Rejects or safely handles invalid channel slug.
5. Rejects or safely handles invalid object type.
6. Rejects or safely handles invalid object id.
7. Rejects thin summaries cleanly if not enough messages.
8. Enforces maxMessages bounds.
9. Excludes soft-deleted message bodies.
10. Excludes attachments from deleted messages.
11. Includes attachment filenames only, not file contents.
12. Does not expose raw filesystem paths.
13. Returns 503 gracefully if AI/OpenAI is unavailable.
14. Handles malformed AI JSON gracefully.
15. Uses existing OpenAI client/wrapper correctly.
16. Uses buildOpenAIModelParams correctly.
17. Does not auto-run summaries on page load.

Summary quality checks

Run test summaries on:

1. #general or another channel with enough messages.
2. A thread with multiple replies.
3. An Account Currents feed with enough messages.
4. A Lead Currents feed if enough messages exist.

Verify output has useful sections:

* Summary
* Key Decisions
* Action Items
* Open Questions
* Risks / Blockers
* Suggested Next Steps

Check:

* Empty sections say None identified.
* Action items have owner/task/due where available.
* Summary does not invent facts not present in messages.
* Summary does not include deleted content.
* Attachment references use filenames only.
* Mention tokens are readable, not ugly raw syntax.
