Proceed with VoltSafe CMS P2 Admin Simplification: Merge Task Rules into Automations Tab.

Do not change navigation broadly. Do not touch CURRENTS, Gmail/mail-permissions, tracking-proof, CRM behavior, Polyweather, or unrelated modules.

Goal

Reduce Admin sidebar clutter by merging Task Rules into Automations as a tab, then removing the standalone Task Rules nav item from Admin.

This is the follow-up cleanup identified after retiring the More group.

Current context

Recent completed work:

* More group retired.
* Task Rules and Automations were moved into Admin.
* Navigation + CURRENTS release shipped and production-confirmed.
* P1 test harness cleanup completed:
    * mail-permissions now 19/19
    * tracking-proof and tracking-multi-proof are guarded behind RUN_LIVE_GMAIL_PROOF=true

Current Admin still has both:

* Task Rules
* Automations

These are conceptually related and should not be two separate sidebar entries long-term.

Required outcome

Admin should have:

* Automations

And inside Automations, there should be tabs such as:

* Automations
* Task Rules

or clearer equivalents if the existing UI already has tab conventions.

The standalone Task Rules sidebar item should be removed only after the Task Rules content is reachable inside Automations.

Scope

Allowed:

1. Audit existing automations page/component.
2. Audit existing task-rules-settings page/component.
3. Add a tabbed interface to the Automations page if one does not already exist.
4. Render the existing Task Rules content inside the Automations page as a tab.
5. Remove standalone Task Rules nav item from Admin.
6. Keep the existing Task Rules route working if safe, either:
    * redirect /automation/tasks to /automations?tab=task-rules, or
    * keep route as a compatibility route but remove it from nav.
7. Update tests.
8. Verify permissions remain unchanged.

Not allowed:

1. Changing task rule business logic.
2. Changing automation business logic.
3. Backend schema changes.
4. Backend API changes unless a tiny route compatibility redirect is needed.
5. Rewriting Automations.
6. Full Admin redesign.
7. CURRENTS changes.
8. Gmail/mail/tracking changes.
9. CRM behavior changes.

First inspect:

* Automations page/component
* Task Rules page/component
