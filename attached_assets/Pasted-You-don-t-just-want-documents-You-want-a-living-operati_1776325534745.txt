What to Ask Replit
 
Use this master prompt:
I want you to create a complete documentation + training system for VoltSafe Cortex (our internal CMS/CRM), and also make it usable by the built-in VoltSafe Cortex AI assistant inside the platform.
 
GOAL:
Create:
1. Full Operations Manual
2. Internal Staff Training Handbook
3. In-app AI Help Knowledge Base for VoltSafe Cortex assistant
4. Fast onboarding materials for new employees
 
IMPORTANT:
Before writing anything, audit the actual codebase so documentation matches real features that exist today.
Do not invent features.
If something is unclear, say “unclear from code”.

- login
- navigation
- dashboard
- command center
- accounts

- contacts

- pipeline
- quotes
- tasks hub
- suggestions
- command bar / search
- gmail inbox

- timelines
- saved views
- bulk actions
- data quality center
- install workflows
- executive dashboard
- source attribution
- admin/settings
- daily workflows
- troubleshooting
- glossary
 
Deliverables:
- Quick Start Guide
- Full Manual
- Daily Use Best Practices
- Top 20 Most Important Things to Remember

PART 2 — INTERNAL STAFF TRAINING HANDBOOK
==================================================
 
Create a separate training handbook for employees.
 
Audience:
New hires and existing team members.
 
Make role-based guides for:
- CEO / Admin
- Sales
- Operations
- Read-only users

- what to do daily
