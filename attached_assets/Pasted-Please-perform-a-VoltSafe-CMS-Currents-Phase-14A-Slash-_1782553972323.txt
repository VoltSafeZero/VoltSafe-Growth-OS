1. Detects / at draft start.
2. Detects /word at draft start.
3. Does not incorrectly trigger on normal text containing /.
4. Filters commands correctly.
5. Escape dismisses menu.
6. Dismissed menu does not immediately reopen until appropriate.
7. Arrow up/down navigation works.
8. Enter selects highlighted command when menu is open.
9. Enter still sends message when menu is closed.
10. Selected command removes slash token from draft.
11. Selected command pill can be cleared.
12. Empty query behavior is sensible.
13. Unknown command behavior is safe.
14. Hook does not cause excessive re-renders.
