Revenue Ops v3 is complete. Build the next highest-value phase: “Executive AI Copilot — Daily Decisions Engine”.

OBJECTIVE
Create a top-level intelligence layer that scans CRM, revenue ops, tasks, email signals, board pack metrics, and pipeline movement, then surfaces the few actions that matter most today.

This should feel like having a sharp chief of staff inside Cortex.

Do not rewrite working systems. Reuse existing APIs, tables, pages, and logic.

PHASE T001 — DATA MODEL
Create minimal new tables:

1) executive_briefs
- id serial primary key
- brief_date text not null unique // YYYY-MM-DD
- headline text not null
- summary text not null
- payload_json jsonb not null
- created_at timestamp default now()

2) executive_alerts
- id serial primary key
- type text not null
- severity text not null // low, medium, high, critical
- title text not null
- description text not null
- linked_object_type text nullable
- linked_object_id integer nullable
- status text default 'open' // open, dismissed, resolved
- score integer default 0
- created_at timestamp default now()

PHASE T002 — INTELLIGENCE ENGINE
Create:
server/services/executive-copilot.ts

Export functions:

1. generateDailyBrief()
- Build one daily brief using live system data
- Include:
  - revenue status
  - gap-to-plan
  - overdue critical tasks
  - stalled opportunities
  - unread important emails
  - new leads worth attention
  - anomalies (drop in pipeline, missed target trend, etc.)
- Return only the top 5 things that matter

2. detectExecutiveAlerts()
Examples:
- Large deal stalled 14+ days
- Commit off-track >15%
- Critical task overdue
- No new qualified leads in 7 days
- Churn risk account inactive
- Board pack scheduled but missing fresh data

3. rankPriorities()
Score alerts based on revenue impact, urgency, age, and proximity to deadline.

4. generateSuggestedMoves()
For each top alert, propose the next best action:
- call X
- send follow-up
- create discount approval
- escalate install timeline
- schedule investor update
- push board pack refresh
