## Notes
- Dark mode is configured to be the default theme.
- Data fetches assume endpoints `/api/metrics`, `/api/chart-data`, and `/api/sales` are available and return seeded data as per the schema.
- Uses `Plus Jakarta Sans` for headings and `Inter` for body typography.
